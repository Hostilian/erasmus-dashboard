# Universitat de Lleida (UdL) - Winter Semester Course Mapping & Alternatives

This document compiles the findings from an extensive research search of the **Grau en Enginyeria Informàtica** (Bachelor in Informatics Engineering) and related degrees at the **Universitat de Lleida (UdL)**, Spain, to map the four required courses for the upcoming Winter Semester exchange.

---

## Detailed Course Syllabus & Rationale

### 1. Operating Systems / UNIX
*   **Option A: Sistemes Operatius (9 ECTS) — 1st Semester (Winter)**
    *   *Department:* Escola Politècnica Superior (EPS)
    *   *Focus:* Process lifecycle, CPU scheduling, memory management (virtual memory, paging), filesystem organization, concurrency/semaphores, and shell programming/command line in UNIX/Linux.
    *   *Alignment:* High. Directly maps to standard CZU Operating Systems/UNIX requirements.
*   **Option B (Alternative): Administració i Manteniment de Sistemes i Aplicacions (6 ECTS) — 1st Semester (Winter)**
    *   *Department:* Escola Politècnica Superior (EPS)
    *   *Focus:* Hands-on system administration. Installation and maintenance of operating systems (mostly Linux/UNIX), configuration of core network services (web, database, DNS, mail servers), security management, backups, and shell scripting.
    *   *Alignment:* High for UNIX/Linux system tools. Perfect if a 6 ECTS course is preferred over 9 ECTS.

### 2. Web Design / Web Technologies
*   **Option A (Alternative): Web dinàmica (6 ECTS) — 1st Semester (Winter)**
    *   *Degree:* Grau en Disseny Digital i Tecnologies Creatives (taught at EPS)
    *   *Focus:* Full-stack backend web development. Taught at the same engineering school. Focuses on server-side technologies, connecting web applications to databases (e.g. PHP/MySQL or Node.js/Express), session handling, web security, and RESTful APIs.
    *   *Alignment:* High. Directly aligns with the programming and functional aspects of Web Technologies.
*   **Option B (Alternative): Disseny Centrat en l'Usuari (6 ECTS) — 1st Semester (Winter)**
    *   *Degree:* Grau en Enginyeria Informàtica (EPS)
    *   *Focus:* UI/UX design, wireframing, mockup development, user testing, usability heuristics, and interface layout principles for web and mobile platforms.
    *   *Alignment:* Moderate-to-High. Focuses on the "design" aspect of Web Design. Taught inside the main Informatics program.

### 3. Statistics
*   **Option A (Alternative): Estadística Avançada (6 ECTS) — 1st Semester (Winter)**
    *   *Degree:* Grau en Administració i Direcció d'Empreses (ADE) / GEIADE Double Degree
    *   *Focus:* Probability theory, random variables, statistical estimation, confidence intervals, hypothesis testing, correlation, and linear regression models.
    *   *Alignment:* High. Perfect equivalent for the core Statistics course, offered during the winter term.

### 4. Accounting
*   **Option A: Fonaments de Comptabilitat (6 ECTS) — 1st Semester (Winter)**
    *   *Degree:* Double Degree in Informatics & ADE (GEIADE) / Grau en ADE (FDET)
    *   *Focus:* Financial accounting cycle, double-entry bookkeeping, recording business transactions, ledger entries, and preparing financial statements (balance sheet, income statement).
    *   *Alignment:* High. Direct match for the CZU Accounting requirement.
